# Contributing

**English** | [Deutsch](#deutsch)

Thank you for helping to improve these charts!

The charts are **generated automatically**. Every run writes all PNG and SVG files again, so manual edits to them would be lost with the next run. That is why pull requests that change files in `png/` or `svg/` cannot be merged, however good the change is.

What helps most is an **issue**: use the [chart error form](https://github.com/sivar2311/DCS-Aerodrome-Charts/issues/new/choose) and tell us

- the map and the airfield,
- the sheet (file name, e.g. `14_GND_OMAA_Abu Dhabi Intl_P1`),
- what is wrong and, if you know it, what is right (e.g. what you see in DCS),
- ideally a screenshot.

The error is then fixed in the generator, so it is fixed on every chart with the same problem.

Corrections to the README texts are welcome as pull requests.

## Deutsch

Danke, dass du helfen möchtest, die Karten zu verbessern!

Die Karten werden **automatisch erzeugt**. Jeder Lauf schreibt alle PNG- und SVG-Dateien neu, Handänderungen daran gingen beim nächsten Lauf verloren. Deshalb können Pull Requests, die Dateien in `png/` oder `svg/` ändern, leider nicht übernommen werden, so gut die Änderung auch ist.

Am meisten hilft ein **Issue**: Nutze das [Formular für Kartenfehler](https://github.com/sivar2311/DCS-Aerodrome-Charts/issues/new/choose) und nenne

- Karte und Flugplatz,
- das Blatt (Dateiname, z. B. `14_GND_OMAA_Abu Dhabi Intl_P1`),
- was falsch ist und, wenn bekannt, was richtig wäre (z. B. was du in DCS siehst),
- am besten einen Screenshot.

Der Fehler wird dann im Generator behoben und damit auf allen Karten mit demselben Problem.

Korrekturen an den README-Texten sind als Pull Request willkommen.
