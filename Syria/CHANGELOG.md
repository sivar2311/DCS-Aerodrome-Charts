# Changelog: Syria

Changes to the Syria charts, newest first. Overview of all maps: [CHANGELOG.md](../CHANGELOG.md).

## 2026-11-20: DCS display names

The names now come from the running game (airbase export of a DCS mission) instead of the internal file names of the map. Before, 11 airfields showed the internal name first and the DCS name only as second name. Chart contents, airfield numbers and codes are unchanged; titles and file names changed.
